# Security Policy

## Supported Versions

We release fixes on the latest release of Metrolist Android Car. Only the most recent release receives security fixes.

| Version | Supported |
|---------|-----------|
| Latest release | ✅ |

## Reporting a Vulnerability

To report a security issue, please **do not** open a public issue.

Instead, use GitHub's [private vulnerability reporting](https://github.com/jajafu/Metrolist_AndroidCar/security/advisories/new) to disclose it privately. A maintainer will respond as soon as possible.

Please include:
- A description of the vulnerability and its impact.
- Steps to reproduce it.
- The version of the app affected (if known).

Thank you for helping keep the project safe.
