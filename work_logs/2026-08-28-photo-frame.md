# 數位相框實作紀錄（13.6.60）

## 範圍與隔離

- 主選單第三格由一起聽改為數位相框；一起聽仍可從設定 → 整合或既有頂部捷徑使用。
- 新增獨立相框 UI、ViewModel、照片來源、JSON 索引與輪播控制器；只共用現有播放控制介面、Coil 與 DataStore，不修改 Room schema 或音樂播放核心。
- 未進入相框不初始化照片來源、不掃描、不解碼。畫面停止時取消載入與計時；暫停點只保留 URI 與時間，不保留 Bitmap。
- 解碼最長邊上限 1920px，只持有目前／下一張，停用相框請求的共用圖片快取；沒有新增依賴、服務、權限或螢幕常亮設定。
- 單張來源使用系統 Photo Picker；資料夾以 SAF / DocumentsContract 遞迴列舉，避免新增 DocumentFile 依賴。原始照片不複製、不刪除。
- Android 系統挑選器可能顯示系統／供應者提供的雲端選項；本 App 沒有整合雲端 API，本次僅驗證本機照片與資料夾。
- 索引採暫存檔＋原子替換；取消掃描保留上次完整索引。失效來源可重新選取或掃描；整個資料夾不可讀時略過其餘 URI。
- 雙語 README、版本號及 `changelog.md` 的 `## 13.6.60` 發行說明已同步。
- 回歸測試發現先存取個別目的地時，主選單清單可能因循環初始化含有空值；改用延遲建立，保留初始化／返回測試。
- 修正壞圖位於一輪末尾時的邊界判斷：以最後成功讀取的照片避免連續重複，不能把預載重複誤判為只剩一張照片；加入 20 個固定種子、各 40 張的連續播放測試。

## 驗證

- 單元測試覆蓋：manifest 原子寫入／損毀復原、遞迴與取消、權限撤銷、照片池合併、來源恢復、隨機不重複、空池／單張／全部失效、載入逾時、暫停續播與主選單返回。
- `:app:assembleFossDebug` 通過；`:app:testFossDebugUnitTest` 共 178 項全部通過，其中相框相關 28 項。
- `:app:lintFossRelease` 通過：0 個阻擋錯誤、30 項警告（相依套件更新、數量字串建議及保留的舊翻譯鍵）。沿用原 baseline，未新增忽略規則或重新產生 baseline；既有 52 項錯誤及 212 項警告仍由 baseline 過濾。
- Android 17 / API 37 獨立唯讀模擬器煙霧測試：確認主選單入口、黑底全螢幕控制層、相框設定與間隔變更、資料夾及子目錄共兩張測試圖掃描、Photo Picker 多選追加、圖片顯示、直向／橫向及 Back 回首頁。未操作已連線的實體手機。
- 本機 JDK 的 Windows Unix-domain loopback 出現 `Invalid argument`；只在測試程序以 `JAVA_TOOL_OPTIONS` 指定不存在的 Unix socket 目錄，讓 JDK 回退 TCP。未修改專案 Gradle 設定或 CI。

## 仍需實機驗收

- API 26 的 picker fallback、重開機後 URI 存取、1000+ 張圖片、中文／特殊檔名。
- 車機 USB 熱插拔、重新掃描、FAT32／exFAT；單元測試模擬失效不等於硬體驗收。
- 播放音樂期間的上一首／下一首與進出相框，以及連播 30 分鐘的記憶體、溫度及耗電。
- 不提供 Android Auto 投影照片；相框僅供停車時使用。

`photo_plan.md` 與模擬器測試圖片／截圖均未加入提交。
